# --- Why exit 0 with a non-empty review queue -----------------------------
#
# Staleness is a BUILD FACT, not a diagnostic (D-024). It carries no AKR-* code,
# never enters the diagnostic stream, and never changes an exit status. The
# ledger is valid; two of its observations have aged. Those are different
# statements and the tool keeps them apart.
#
